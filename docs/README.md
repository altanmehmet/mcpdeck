Published releases can lag the source branch. Check your installed version's
help before using newly documented commands. Test records distinguish file
adapter coverage from real agent sessions; neither guarantees all MCP services.

Report reproducible problems through [GitHub Issues](https://github.com/altanmehmet/mcpdeck/issues).
Include the application version, operating system, agent version and sanitized
steps to reproduce. Keep credentials and personal configuration out of issues.
